## Install

```sh
brew install jorisnoo/tap/gds-fm
```

Or download the latest DMG from [Releases](https://github.com/jorisnoo/GDSPlayer/releases/latest).

## Requirements

- macOS 15+ (Catalina)
- Xcode 16+

## Build

1. Open `GDSPlayer.xcodeproj` in Xcode
2. Build and run (⌘R)

For releases, signed builds and notarisation, see [RELEASING.md](RELEASING.md).
